바이탈트레이스 · 개인정보 처리방침
최종 수정: 2026-10-28

한 줄 요약: 이 앱은 건강 데이터를 업로드하지 않습니다. 모든 기록은 이 휴대폰에만 저장되며, 유일한 전송은 끌 수 있는 익명 사용 통계(6항)입니다.

1. 데이터 출처
· 삼성 헬스: 사용자가 허용한 경우 수면, 심박수, 산소포화도, 걸음 수 등의 기록을 읽습니다.
· 워치 앱: 워치에서 측정한 심전도, 산소포화도, 체온 등을 블루투스로 전송받습니다.
· 직접 입력: 혈압, 혈당, 생리 기록 등.

2. 데이터 저장 위치
모든 데이터는 이 기기의 앱 전용 데이터베이스에 저장되며 어떤 서버로도 전송되지 않습니다.
앱을 삭제하면 전부 지워지고, 앱 안에 "데이터 비우기" 기능도 있습니다.
"백업"은 사용자가 직접 실행하며, 내보낸 파일은 사용자가 선택한 위치에 저장됩니다.

3. 네트워크 사용
앱이 네트워크를 쓰는 경우는 다음 세 가지이며, 모두 앱이 직접 요청합니다. 앞의 두 가지는 기기 식별자·계정·건강 데이터를 포함하지 않고, 세 번째는 끌 수 있는 익명 사용 통계입니다.

- 공지 가져오기: 실행 시 공개 공지 파일(JSON)을 읽어 업데이트 소식을 보여줍니다.
  공지 주소: https://REPLACE-ME.invalid/announcement.json
- 업데이트 확인 및 설치: 실행 시 또는 "업데이트 확인"을 눌렀을 때 그 파일에 적힌 최신 버전과 비교하며, 사용자가 확인한 경우에만 안내된 주소에서 새 설치 파일을 내려받아 크기와 SHA-256을 검증한 뒤 시스템 설치 프로그램에 넘깁니다. 확인하지 않으면 아무것도 내려받지 않습니다.
- 익명 사용 통계(선택, 기본 꺼짐): 첫 실행 시 「동의하고 계속」을 누른 뒤에만 앱 버전, 휴대폰 모델, OS 버전, 인터페이스 언어, 기능 사용 여부(예: 「심전도를 측정했는지, 성공했는지」), 무작위 설치 ID를 전송합니다. 측정값은 포함되지 않으며 전화번호, 계정, 위치, 기기 식별자도 수집하지 않습니다. 6항 참고.

공지나 업데이트 정보를 가져오지 못해도 기기 내 기능에는 영향이 없습니다.
"정보"에서 "온라인으로 보기"를 누르면 시스템 브라우저가 공개 개인정보 처리방침 페이지를 엽니다(해당 요청은 브라우저가 보냅니다).

4. 권한의 용도
· 블루투스: 워치 연결 및 측정값 수신.
· 네트워크: 공지 수신, 업데이트 확인·다운로드, 그리고 (선택) 익명 사용 통계 전송.
· Health Connect 읽기/쓰기: 앱의 측정값을 시스템 건강 데이터에 기록(선택, 언제든 철회 가능).

5. 제3자
계정도, 광고도, 제3자 분석 SDK도 없습니다. 유일한 외부 전송은 자체 익명 사용 통계(6항)이며 자체 Cloudflare 서비스에만 기록합니다. 데이터를 제3자와 공유하거나 판매하지 않습니다.

6. 익명 사용 통계
- 보낼지는 사용자가 결정합니다: 첫 실행 시 묻고 기본값은 꺼짐입니다. 이후 「사용자」 페이지의 「익명 사용 통계」 스위치로 언제든 끌 수 있습니다.
- 보내는 항목: 앱 버전, 휴대폰 모델과 OS 버전, 인터페이스 언어, 이벤트 이름과 성공 여부(예: 「심전도 측정 성공」), 무작위 설치 ID.
- 보내지 않는 항목: 모든 측정값(심박수, 혈압, 산소포화도, 체온, 수면 등)과 전화번호, 계정, 위치, IMEI / Android ID 등 기기 식별자.
- 저장 위치: 자체 Cloudflare 통계 서비스에만 기록하며 버전·기기 분포 파악에 사용합니다. 스위치를 끄면 즉시 전송이 중단되고 설치 ID가 삭제됩니다.
- 설치 ID는 하드웨어와 무관한 무작위 문자열입니다. 재설치하면 바뀌며, 이를 이용해 사용자를 찾아낼 수 없습니다.

7. 사용자의 권리
시스템 설정에서 언제든 권한을 철회할 수 있고, 앱을 삭제하면 로컬 데이터가 모두 지워집니다.

8. 아동
이 앱은 만 13세 미만 아동을 대상으로 하지 않습니다.

9. 변경 및 문의
방침이 변경되면 앱 업데이트와 함께 앱 안에서 안내합니다. 문의: contact@example.com
